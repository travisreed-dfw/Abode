# Phones, tablets and browser tips

All pages are laid out for phone and tablet widths, and Abode can be installed as an app.

## Install as an app

- **iPhone and iPad**: open `http://a/` in Safari, tap Share, then **Add to Home Screen**.
- **Android and desktop Chrome**: use **Install app** in the browser menu; on phones a one-tap prompt appears on the home page.

The icon is drawn in the theme you had selected when you installed. Installed apps load the live pages every time, so updates need no reinstall; only a changed icon or name would.

## Browser tips

- Typing just `a` in the address bar may trigger a web search. Type **`a/`** (with the slash) or the full `http://a/` to force navigation. After the first visit most browsers will autocomplete it.
- If a browser insists on `https://a/`, type `http://a/` explicitly once. The server is plain HTTP and only meant for your local network.
- **Make `a` a keyword.** Add a custom search engine in Chrome (Settings → Search engine → Manage → Add) or Firefox (bookmark with a keyword) with the URL `http://a/%s` and the keyword `a`. Then typing `a`, space, `gh` in the address bar goes straight to the alias, and the "is `a` a search?" problem disappears.
- **Make it your new-tab page.** Set the browser's home page / new-tab page to `http://a/` to land on the search bar and bookmarks.
- **Phones and tablets.** All pages are laid out for phone and tablet widths. On an iPhone or iPad, open `http://a/` in Safari, tap Share → **Add to Home Screen**; on Android and desktop Chrome use **Install** in the browser menu. Either way you get a Abode icon, drawn in the theme you had selected when you installed, that opens full-screen to the search bar.
