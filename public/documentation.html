Home page

The name a is just the DNS record your network points at this server; if yours is called something else, every example on these pages already shows the name you used to get here.

http://a/ is a start page for everyone on the network. The first visit asks for a username. There are no passwords: Register creates a new profile, Log in opens an existing one, and the browser remembers the choice for a year. If a name is already taken, Register says so; pick another.

Each profile has its own default search engine, its own bookmarks and its own color theme. Aliases are shared by everyone.

Themes. The dropdown in the top bar switches the colors for your profile: the default Midnight plus palettes inspired by popular editor themes (Dracula, Monokai, One Dark, Solarized, Nord, Gruvbox, Tokyo Night, Catppuccin, GitHub, Night Owl, SynthWave '84, Pink Cat Boo, Doki's Nekopara Chocola, and two light ones). Your choice is saved to your profile and follows you to the aliases and documentation pages in this browser, and the tab icon and home-screen icon are drawn in the same colors.

Search and bangs

Type anything into the search bar and press Enter. Where it goes, in order:

  1. A !bang anywhere in the query picks where it goes: !w red panda or red panda !w searches Wikipedia, !book jackson sends the word to your book alias, !book alone opens it. Bangs that aren't built in and aren't one of your aliases (DuckDuckGo supports thousands, such as !hn or !gm) are handed to DuckDuckGo, which resolves them.
  2. Otherwise the engine in the dropdown is used. Plain words never jump to an alias, so book jackson is an ordinary search even though a book alias exists.

Every bang is also a path on this server, so the same shortcuts work from any address bar without opening the home page: http://a/yt/kitty cats searches YouTube, http://a/yt opens it.

Your aliases as bangs

Every alias on the aliases page works the same way as a built-in bang: !name words in the search bar, or http://a/name/words in an address bar. An alias whose target contains %s receives the words as a search term; otherwise they're appended to its path.

Aliases

An alias is a short name for a URL: http://a/gh can send you to https://github.com. Manage them on the aliases page.

  • Names are lowercase letters, numbers, dots, dashes and underscores, up to 64 characters. Capitalisation doesn't matter when you use them.
  • Extra path is passed through. http://a/gh/travisreed → https://github.com/travisreed. A query string is passed along too.
  • Search aliases. Put %s in the target where the words should go: https://www.google.com/search?q=%s makes http://a/g/cats a search. This is how you make your own bangs.
  • Unknown names take you to the aliases page with the name prefilled, so http://a/newthing is the fastest way to create newthing.
  • Descriptions are optional notes shown in the list. Hits count every redirect so you can see what's used.
  • Export / Import download and restore a JSON backup of aliases, profiles and bookmarks. Importing updates existing entries and adds new ones; it never deletes. The server also writes a backup by itself every day and keeps the last thirty.
  • Profiles are listed at the bottom of the aliases page. Deleting one (tick the box, type its name) removes that profile and its bookmarks, for cleaning up names made in error.
  • Reserved names: api, aliases, assets, documentation, and the built-in bang names above.

Bookmarks

The buttons under the search bar. Press Edit, give each one a label and a URL, then Save. A URL can be a full address or a path on this server, such as /aliases or /plex. The server fetches each site's icon once and keeps it; sites without a usable icon get a colored tile with the first letter of the label.

  • Shared puts a bookmark on everyone's home page. Anyone can edit a shared bookmark; removing it removes it for all.
  • Hidden takes a bookmark off your page without affecting anyone else. Useful for shared ones you don't need. Hidden rows still appear in Edit, sorted to the bottom, so you can bring them back.
  • Order is yours alone: the arrows in Edit arrange the buttons on your page.
  • Groups. Give a bookmark a group name in Edit and the home page shows it in a collapsible section. Which sections you've collapsed is saved to your profile, so your phone and laptop match. Sections appear in the order their first bookmark appears.
  • Docker. If the person running Abode has turned on Docker discovery, containers labelled abode.name appear as shared bookmarks for everyone. You can hide or reorder them but not edit them; a stopped container shows a red dot.
  • Status dot. Bookmarks that point at something on the home network (a private IP, a name without dots, or an alias to one) get a green or red dot showing whether the service answered in the last minute. Internet sites get no dot; the server never pings them.

Tips

  • Address bar keyword. Add a custom search engine in your browser with the URL http://a/%s and the keyword a. Then a, space, yt kitty cats in the address bar goes straight there.
  • New-tab page. Set the browser's home or new-tab page to http://a/.
  • Install it. On iPhone or iPad use Share → Add to Home Screen; on Android and desktop Chrome use the Install option in the browser menu. It opens full-screen with its own icon.
  • Typing just a may trigger a web search. Type a/ with the slash, or http://a/, the first time; browsers autocomplete it after that.
